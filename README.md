Most of my work sits where an LLM meets real infrastructure — vector search over
private documents, agents that make decisions mid-conversation, and the auth,
storage and deployment layers that make those usable by someone other than me.

Six projects below, all built end-to-end: the retrieval pipeline *and* the app
around it. MCA student in Pune, open to backend and AI engineering roles.

### Selected projects

<table>
<tr>
<td width="50%" valign="top">

#### 🔍 [RAGForge](https://github.com/Kushwaha-Hemant/RAGForge-Document_Search)
Self-hosted document search. Upload private docs, ask questions, get **cited**
answers. Multi-tenant from the ground up — Clerk auth, per-user isolation,
pgvector similarity search over chunked embeddings.

`Next.js` `FastAPI` `Supabase pgvector` `Clerk`

</td>
<td width="50%" valign="top">

#### 🎙️ [InterviewPilot AI](https://github.com/Kushwaha-Hemant/Interviewpilot_AI)
Not a fixed question list. It grades each answer, then decides what to do next —
probe deeper, hint, or move on — via OpenAI Structured Outputs, so the control
flow is *typed* rather than parsed out of prose.

`Next.js 16` `FastAPI` `PostgreSQL` `OpenAI`

</td>
</tr>
<tr>
<td width="50%" valign="top">

#### 📄 [ResumePilot](https://github.com/Kushwaha-Hemant/ResumePilot)
Scores a resume against a job description, surfaces skill gaps, generates
interview questions, exports a PDF report. LLM provider is pluggable — OpenAI or
Gemini behind one RAG pipeline.

`Streamlit` `LangChain` `ChromaDB` `MiniLM`

</td>
<td width="50%" valign="top">

#### ⚙️ [DevFlow](https://github.com/Kushwaha-Hemant/Devflow)
Repos, pipelines, containers and deployments in one dashboard. The integrations
are **real, not mocked** — pipelines genuinely clone, build an image, and run it
through the Docker Engine API.

`React` `Express` `Prisma` `Socket.IO` `Docker`

</td>
</tr>
<tr>
<td width="50%" valign="top">

#### 💸 [Spendee](https://github.com/Kushwaha-Hemant/Spendee)
AI personal finance, as a monorepo: a native Android app — Jetpack Compose, 14
Gradle modules — beside a Spring Boot backend. Built to practise modularization
at a scale where it starts to matter. *In active development.*

`Kotlin` `Compose` `Spring Boot` `Java`

</td>
<td width="50%" valign="top">

#### 🌌 [DevVerse AI](https://github.com/Kushwaha-Hemant/Devverse_AI) · [live ↗](https://devverse-ai.kushwaha-hemant.workers.dev)
A workspace you explore instead of a page you scroll. Click an object, the camera
flies to it, and it opens a real section of the site. Deployed to the edge.

`React Three Fiber` `Next.js 16` `Tailwind v4` `Workers`

</td>
</tr>
