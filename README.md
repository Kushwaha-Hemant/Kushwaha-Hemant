### Selected projects

**[RAGForge](https://github.com/Kushwaha-Hemant/RAGForge-Document_Search)** — Self-hosted document search platform  
Upload private documents, ask questions, get cited answers. Multi-tenant from the
ground up: Clerk auth, per-user isolation, and pgvector similarity search over
chunked embeddings.  
`Next.js` `FastAPI` `Supabase pgvector` `Clerk`

**[InterviewPilot AI](https://github.com/Kushwaha-Hemant/Interviewpilot_AI)** — Adaptive mock interviewer  
Not a fixed question list. It grades each answer, then decides what to do next —
probe deeper, drop a hint, or move on — using OpenAI Structured Outputs so the
control flow is typed rather than parsed out of prose.  
`Next.js 16` `FastAPI` `PostgreSQL` `OpenAI Structured Outputs`

**[ResumePilot](https://github.com/Kushwaha-Hemant/ResumePilot)** — RAG resume analyzer  
Scores a resume against a job description, surfaces skill gaps, generates
interview questions, and exports a PDF report. The LLM provider is pluggable —
OpenAI or Gemini behind one RAG pipeline.  
`Streamlit` `LangChain` `ChromaDB` `sentence-transformers`

**[DevFlow](https://github.com/Kushwaha-Hemant/Devflow)** — DevOps & CI/CD dashboard  
Repos, pipelines, containers and deployments in one place. The integrations are
real, not mocked: repositories come from the GitHub REST API, and pipelines
actually clone, build an image, and run it through the Docker Engine API.  
`React` `Express` `Prisma` `Socket.IO` `Docker`

**[Spendee](https://github.com/Kushwaha-Hemant/Spendee)** — AI personal finance platform *(in active development)*  
A monorepo pairing a native Android app — Jetpack Compose, 14 Gradle modules —
with a Spring Boot backend. Built to practise modularization at a scale where it
actually starts to matter.  
`Kotlin` `Jetpack Compose` `Spring Boot` `Java`

**[DevVerse AI](https://github.com/Kushwaha-Hemant/Devverse_AI)** — 3D interactive portfolio · **[live ↗](https://devverse-ai.kushwaha-hemant.workers.dev)**  
A workspace you explore instead of a page you scroll. Click an object, the camera
flies to it, and it opens a real section of the site. Deployed to the edge on
Cloudflare Workers.  
`React Three Fiber` `Next.js 16` `Tailwind v4` `Cloudflare Workers`
